## Three Products, One Security Layer

<CardGroup cols={3}>
  <Card title="Security Proxy" icon="shield-halved" href="/proxy/quickstart">
    Local Fastify server (port 8080) that intercepts every LLM request. 6 scanners, policy engine, token intelligence, cost-aware routing. Works with any OpenAI-compatible client.
  </Card>
  <Card title="IDE Extensions" icon="code" href="/ide-extensions/install">
    VS Code extension + JetBrains plugin. Auto-starts proxy, shows scan results in-editor, inline completions, chat, agent mode. All requests go through the firewall.
  </Card>
  <Card title="Control Plane" icon="mobile" href="/proxy/architecture">
    Approve/deny AI agent actions from your phone. WebSocket push notifications, Slack/email alerts, cross-device session tracking. PWA — no app install needed.
  </Card>
</CardGroup>

## Feature Highlights

<CardGroup cols={2}>
  <Card title="75% Token Savings" icon="chart-line">
    Context reduction strips comments and irrelevant code before sending to the LLM. Real tiktoken counting — not character heuristics.
  </Card>
  <Card title="15+ Security Scanners" icon="radar">
    Core pipeline (secrets, PII, entropy, injection) plus advanced scanners: RAG injection shield, multi-turn tracking, behavioral fingerprinting, grounding engine, multi-modal scanning, and more.
  </Card>
  <Card title="60+ LLM Providers" icon="brain">
    OpenAI, Anthropic, Gemini, Ollama, and 56 more. Switch providers without code changes. BYOK with AES-256-GCM encrypted vault.
  </Card>
  <Card title="MCP Security Gateway" icon="plug">
    Every MCP tool call (filesystem, GitHub, Slack, Gmail) scanned for secrets/PII. No competitor does this.
  </Card>
</CardGroup>
