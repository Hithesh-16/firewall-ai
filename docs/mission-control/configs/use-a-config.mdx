## Steps to use a custom configuration in AI Firewall

Once you've found the configuration you want to use on AI Firewall Mission Control:

1. Click “Add Config” on its page
2. Add any required inputs (e.g. secrets like API keys)

After saving, open the AI Firewall CLI or IDE extension and

- Select the configuration from the **config dropdown** in the AI Firewall extension
- Type `/config` and select the configuration in the AI Firewall CLI
- Begin using it for chat mode, agent mode, or other configured capabilities.
