Core Scanners (@ai-firewall/scanner)

K Secret Scanner

12 patterns: AWS keys, GCP, Azure, private keys (PEM/RSA/EC), JWT, database URLs, GitHub tokens, generic API keys, Slack tokens, Stripe keys, SendGrid keys.

P PII Scanner

7 patterns: Email, phone, SSN, Aadhaar, PAN, credit card numbers, IP addresses. Masked output: keys show first 4 + last 2 chars.

E Entropy Scanner

Shannon entropy analysis. High-entropy strings (potential secrets) flagged when above threshold and adjacent to context keywords (key, token, secret, password).

I Prompt Injection Scanner

23 categories: instruction override, role-play, delimiter injection, encoding tricks, ignore-previous, DAN jailbreak, indirect injection (10 patterns).

Advanced Scanners (proxy/src/scanner/)

Multi-Turn Tracker

Session-level escalation detection. Flags rising risk over 3+ turns, category pivots (>60% change), and repetition (same hash 3+ times). 30min TTL.

RAG Injection Shield

17 patterns for document/chunk scanning before RAG ingestion. Catches instruction override, delimiter injection, encoding tricks, whitespace padding.

Intent Clustering

SimHash fingerprinting with 3-word n-gram shingles. Detects coordinated attacks: 3+ distinct users cluster within 5min, Hamming distance < 5.

Behavior Fingerprinting

Per-user profiling: prompt length, word count, vocabulary diversity, frequency, time-of-day. Z-score anomaly detection (>2 std devs, 10 sample min).

Prompt Confidentiality

22 weighted patterns detecting system prompt extraction: direct requests, role-play, translation, encoding, model inversion, training data extraction.

Cross-Model Correlation

Correlates attacks across GPT-4/Claude/Gemini. SimHash similarity + user ID matching. 2 models=medium, 3+=high, 3+ AND 2+ users=critical.

Multi-Modal Scanner

Image (11 OCR patterns), audio (10 phonetic/SSML), structured files (12 patterns: HTML hidden, CSV formula, JSON prototype, PDF JS, XML XXE).

Grounding Engine

Hallucination check: Jaccard overlap (40%), bigram overlap (25%), exact substring (20%), entity overlap (15%). Per-claim and overall scores.

RBAC Model

A Admin

Full access. Inherits org baseline without override. Can manage users, orgs, providers, policies.

S Security Lead

Response scanning ON, audit logs required, prompt injection threshold 50, all requests logged.

D Developer

Day-to-day coding. Blocks credential patterns, prompt injection threshold 40, all requests logged.

U Auditor

Maximum paranoia. All blocks + all redactions + response scanning. Severity threshold: medium (strictest).

Gateway & Smart Routing

Provider adapters normalize formats. Smart router picks the right provider based on risk and cost.

O OpenAI Adapter

Passthrough — native OpenAI format. GPT-4o, GPT-4, o1, o3. Encoding: o200k_base / cl100k_base.

A Anthropic Adapter

OpenAI messages → Anthropic format (system prompt extraction, content blocks). Claude 3/4 family.

G Gemini Adapter

OpenAI → Gemini format (parts-based content). Gemini Pro/Ultra. Via REST API.

L Ollama Adapter

OpenAI → Ollama REST. Local models: Llama 3, Mistral, CodeLlama. Full offline capability.

Token Intelligence

Token Counter

js-tiktoken (WASM BPE). Resolves encoding per model: o200k_base for GPT-4o/o1/o3, cl100k_base for GPT-4/Claude/Gemini/Llama. 4 tokens overhead per message. Fallback: ~4 chars/token.

Cost Estimator

Input tokens (actual) × model pricing. Output estimate: max(256, 25% of input). Returns inputCost, outputCost, totalCost, method. 6 decimal precision.

Context Window

Advisory only — NEVER truncates. Reserves 4096 tokens for output. Returns fits/overageTokens/utilizationPercent. Sets X-AF-Context-Overflow header.
