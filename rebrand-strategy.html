Future Rename Strategy

When the product name changes again, update one file:

// packages/brand/src/index.ts — Change these values: name: "New Product Name", nameLower: "new-product", globalDir: ".new-product", envPrefix: "NEW_PRODUCT", appUrl: "https://new-product.dev", // ... rebuild all packages

Note: Config directory migration (moving ~/.ai-firewall/ to ~/.new-product/) would need a one-time migration script. The altDirs array in BRAND supports backward-compatible directory checking.
