Production Deployment Checklist
Everything needed to go from local dev to production
Pre-Deployment (Do First)
Critical Path
  • ☐ Rotate Google OAuth credentials in Google Cloud Console
  • ☐ Generate new MASTER_KEY and JWT_SECRET
  • ☐ Create WorkOS OAuth app → get new client IDs
  • ☐ Register domain ai-firewall.dev and configure DNS
  • ☐ Verify proxy/.env is in .gitignore and not tracked
  • ☐ Create .env.example template files for proxy, core, CLI
Infrastructure Setup
Hosting
  • ☐ Deploy proxy server (Fastify, port 8080) — Docker or bare metal
  • ☐ Deploy GUI (Vite build, static hosting or CDN)
  • ☐ Set up reverse proxy (nginx/Caddy) with TLS for api.ai-firewall.dev
  • ☐ Configure SSL certificates (Let's Encrypt or similar)
  • ☐ Set up CI/CD pipeline (GitHub Actions — update workflow secrets)
  • ☐ Configure production SQLite path or PostgreSQL (Phase 5)
External Service Accounts
Accounts
  • ☐ WorkOS — Create organization + OAuth app
  • ☐ Google Cloud — Create OAuth consent screen + credentials
  • ☐ PostHog — Create new project, get API key
  • ☐ GitHub — Create OAuth app (optional SSO)
  • ☐ Sentry — Create project, get DSN (optional)
  • ☐ npmjs.com — Claim @ai-firewall scope (for publishing)
Post-Deployment Verification
Testing
  • ☐ Test WorkOS login flow end-to-end
  • ☐ Test Google SSO login through proxy
  • ☐ Test scanner pipeline (secret + PII detection)
  • ☐ Test LLM proxy flow (chat completions route)
  • ☐ Verify /health endpoint returns OK
  • ☐ Test VS Code extension connects to production proxy
  • ☐ Verify telemetry events reaching PostHog
  • ☐ Load test with concurrent requests
★
Future Rename Strategy

When the product name changes again, update one file:

// packages/brand/src/index.ts — Change these values: name: "New Product Name", nameLower: "new-product", globalDir: ".new-product", envPrefix: "NEW_PRODUCT", appUrl: "https://new-product.dev", // ... rebuild all packages

Config directory migration (moving ~/.ai-firewall/ to ~/.new-product/) would need a one-time migration script. The altDirs array in BRAND supports backward-compatible directory checking.
