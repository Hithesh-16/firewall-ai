Request Flow (All 9 Security Layers)

Extension/CLI -> localhost:8080/v1/chat/completions
  1. Auth (Bearer token, RBAC check)
  2. Rate Limit (per-user)
  3. Unicode Normalization (strip zero-width, map confusables, remove bidi)
  4. Scanner Pipeline (secrets, PII, entropy, context adjust, prompt injection)
  5. Policy Engine (BLOCK/REDACT/ALLOW)
  6. Token Count + Cost Estimate + Context Window Check (advisory)
  7. Redactor (if REDACT)
  8. Gateway Router -> Provider Adapter -> AI Provider
  9. Response Scanner (secrets/PII in output)
  -> Audit Log -> X-AF-* headers -> Response
