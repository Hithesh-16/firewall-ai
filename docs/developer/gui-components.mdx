## Overview

The GUI is a React + Vite + Tailwind application serving as both an IDE webview and a standalone web dashboard. Environment-aware routing hides web-only pages (security, agents, tasks) inside the IDE.

## Pages

| Route | Page | Phase | Description |
|-------|------|-------|-------------|
| `/` | Chat | Core | Main chat interface |
| `/history` | History | Core | Conversation history |
| `/stats` | Stats | Core | Usage statistics |
| `/config` | Config | Core | Settings (models, rules, tools) |
| `/security` | Security | Core | Security dashboard (web only) |
| `/agents` | Agent Manager | P1 | Active agents, approvals, coordinator |
| `/tasks` | Task Dashboard | P1 | Task list, progress, kill controls |
| `/memory` | Memory Browser | P1 | Memory index, editor, type filtering |
| `/setup` | Setup Wizard | P3 | Onboarding: env, provider, security, scan |
| `/onboarding` | Onboarding | Core | Org/team setup flow |
| `/rbac` | RBAC | Core | Role-based access control |
| `/team` | Team Dashboard | Core | Team management |

## Theme System

All components use theme-mapped Tailwind classes. No hardcoded colors.

| Purpose | Class | Wrong |
|---------|-------|-------|
| Background | `bg-editor`, `bg-input`, `bg-secondary-background` | `bg-gray-800` |
| Text | `text-foreground`, `text-description`, `text-description-muted` | `text-white` |
| Semantic | `text-error`, `text-warning`, `text-success`, `text-info` | `text-red-500` |
| Borders | `border-border`, `border-border-focus` | `border-gray-600` |
| Buttons | `bg-primary text-primary-foreground` | `bg-blue-500 text-white` |

### Design Rules

1. Every async operation shows a loading state
2. Every list shows an empty state with guidance
3. Every error shows a user-friendly message (never raw JSON)
4. Icon buttons have `aria-label` for accessibility
5. All interactive elements have visible focus states
6. Unicode in JSX uses `{"\u23CE"}` not `\u23CE`
