## Base URL

```
http://localhost:8080
```

## Authentication

Requests can be authenticated via:
- `Authorization: Bearer afw_xxxxx` — AI Firewall API token
- `Authorization: Bearer sk-xxxxx` — Passthrough provider key (forwarded directly)

## All Endpoints

### LLM Proxy
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/v1/chat/completions` | OpenAI-compatible proxy with scanning |
| POST | `/api/estimate` | Pre-flight token + cost + scan estimate |
| GET | `/health` | Health check |

### File Scanning
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/scan/file` | Scan single file (cached by SHA-256) |
| POST | `/api/scan/batch` | Scan up to 50 files with summary |
| DELETE | `/api/scan/cache` | Clear scan cache |
| GET | `/api/scan/cache/stats` | Cache statistics |

### Context Reduction
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/reduce` | Reduce content via grep+window+strip pipeline |

### MCP Security Gateway
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/v1/mcp/tools/call` | Scan tool inputs, forward, scan outputs |
| POST | `/v1/mcp/scan` | Standalone text scan |
| GET | `/v1/mcp/audit` | Query MCP audit log |
| GET | `/v1/mcp/audit/stats` | Aggregate MCP stats |

### Approvals & Sessions
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/approvals/pending` | List pending approvals |
| POST | `/api/approvals/:id/resolve` | Respond (allow/deny) |
| GET | `/api/approvals/history` | Past decisions |
| GET | `/api/approvals/rules` | Remembered rules |
| GET | `/api/sessions/active` | Active sessions across devices |

### Notifications
