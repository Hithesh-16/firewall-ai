Phase 1: Agent Core Intelligence

4-5 weeks • 23 new files • 2 modified • 3 new DB tables

Goal: Match claude-code's core agent capabilities — task management, sub-agent spawning, persistent memory, plan mode, context compaction. These are table-stakes for a modern AI coding agent.

1A. Task Framework (Week 1)

What: Task state machine with 7 types, disk persistence, progress tracking.

  • Create proxy/src/tasks/taskTypes.ts — TaskType union, TaskStatus enum, TaskStateBase interface
  • Create proxy/src/tasks/taskFramework.ts — registerTask(), updateTaskState(), cleanup()
  • Create proxy/src/tasks/localAgentTask.ts — Agent task lifecycle
  • Create proxy/src/tasks/backgroundTask.ts — Background execution + WS notifications
  • Create proxy/src/services/taskService.ts — CRUD for tasks table
  • Create proxy/src/routes/task.route.ts — REST endpoints
  • Add tasks table to proxy/src/db/database.ts
Pattern Reference (from claude-code)
Task.ts interface:
TaskType = 'local_bash' | 'local_agent' | 'remote_agent' | 'dream' | ...
TaskStatus = 'pending' | 'running' | 'completed' | 'failed' | 'killed'
TaskStateBase = { id, type, status, description, outputFile, startTime, endTime, notified }
IDs are prefixed: b* (bash), a* (agent), r* (remote), d* (dream).
Output persisted to disk (JSONL). Progress tracked via ProgressTracker {toolUseCount, tokenCounts, recentActivities}.

1B. Tool Permission Layer (Week 1-2)

What: Permission checking for every tool call — config rules, auto-classify, interactive dialog.

  • Create core/tools/toolPermissions.ts — hasPermissionsToUseTool(), 3-level decision
  • Create core/tools/toolRegistry.ts — assembleToolPool() (built-in + MCP, deduped)
  • Modify existing tools to add isReadOnly(), isDestructive() flags
Pattern Reference (from claude-code)
Decision flow:
1. Check deny rules (blanket deny, pattern: Bash(rm *))
2. Check allow rules (blanket allow, pattern: Read(**))
3. Auto-mode classifier (Bash commands classified as safe/unsafe)
4. Interactive dialog (ask user: allow-once, allow-always, deny)
PermissionContext: mode, alwaysAllowRules, alwaysDenyRules, alwaysAskRules

1C. Persistent Memory (Week 2)

What: File-based memory system with typed entries (user/feedback/project/reference).

  • Create proxy/src/memory/memdir.ts — MEMORY.md index, truncation, buildMemoryPrompt()
