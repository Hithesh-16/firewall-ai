AI Firewall is a **local-first security proxy** that sits between your developer tools (VS Code, CLI, JetBrains) and AI providers (OpenAI, Anthropic, Gemini, Ollama). It intercepts every AI-bound request, scans for secrets and PII, then blocks, redacts, or forwards the cleaned prompt — all before data ever leaves your machine.

## Quickstart

<Steps>
<Step title="Install">
```bash
npm install
cd packages/scanner && npm run build
cd proxy && npm run build && npm start
```
The proxy starts on `http://localhost:8080`.
</Step>

<Step title="Configure your AI tool">
Point your VS Code extension, CLI, or any OpenAI-compatible client to the proxy:
```
API Base URL: http://localhost:8080/v1
```
Every request now passes through the security scanner pipeline.
</Step>

<Step title="Verify it works">
```bash
curl -X POST http://localhost:8080/api/estimate \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4","messages":[{"role":"user","content":"My AWS key is AKIAIOSFODNN7EXAMPLE"}]}'
```
Response shows: `secretsFound: 1`, `action: "BLOCK"`, `riskScore: 100`.
</Step>
</Steps>

## How it works

```
Your IDE / CLI / Browser
    ↓
AI Firewall Proxy (localhost:8080)
    ↓
┌─────────────────────────────────┐
│  1. Token Counting (tiktoken)   │
│  2. Secret Scanner (12 patterns)│
│  3. PII Scanner (7 patterns)    │
│  4. Entropy Scanner (Shannon)   │
│  5. Prompt Injection (13 types) │
│  6. Policy Engine (BLOCK/REDACT)│
│  7. Context Window Advisory     │
│  8. Cost-Aware Routing          │
└─────────────────────────────────┘
    ↓
AI Provider (OpenAI / Anthropic / Gemini / Ollama)
```

Every request is scanned. Every tool call is audited. No secrets reach the LLM.
